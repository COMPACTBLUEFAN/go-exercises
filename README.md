# go-exercises

Сборник упражнений на Go, выполненных в рамках Фазы 0.

## Структура
- `interfaces/` — интерфейсы, полиморфизм (Formatter, Error)
- `concurrency/` — горутины, каналы, WaitGroups, Mutex
- `pingpong/` — ping-pong через каналы
- `algo-combo/` — комбинации структур и алгоритмов
- `experiments/` — эксперименты
- `stack/` - стеки
- `structs/` - структуры
- `slices/` - срезы
- `maps/` - карты

## Запуск
```bash
# Запустить конкретный файл
go run <path_to_file> [args]
# Примеры:
go run algo-combo/stack-queue/main.go
go run concurrency/concurrency/main.go
go run interfaces/interfaces/main.go
go run pingpong/pingpong/main.go
go run stack/stack/main.go
go run structs/structs/main.go
go run slices/slices/main.go
go run maps/maps/main.go
```
